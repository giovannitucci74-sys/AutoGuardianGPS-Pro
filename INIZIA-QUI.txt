AUTOGUARDIAN GPS PRO — PRIMA PROVA

Non devi programmare nulla.

1) Estrai lo ZIP.
2) Crea un repository pubblico GitHub: AutoGuardianGPS-Pro
3) Add file > Upload files
4) Trascina TUTTO il contenuto della cartella AutoGuardianGPS-Pro
5) Commit changes
6) Aspetta che GitHub finisca la compilazione
7) Apri Releases
8) Scarica AutoGuardianGPS-Pro-debug.apk
9) Installa sul telefono Android 13
10) Concedi Localizzazione e premi ATTIVA TRACKING

La build parte automaticamente dopo il caricamento.
VERSIONE CORRETTA PER GITHUB ACTIONS
====================================

Questa versione usa Gradle 8.10 direttamente e non richiede il file gradlew.
In GitHub Actions avvia esclusivamente il workflow:
"CREA APK - VERSIONE CORRETTA".
